# NaSX Cinema OS

**Version:** 2.0 (Development)  
**Platform:** Android TV  
**Project Type:** Native Android TV Launcher  
**Package:** com.nasx.cinemaos  
**Developer:** Musthafa K Siyad

## Project Overview

NaSX Cinema OS is a custom Android TV launcher designed to deliver a premium cinematic entertainment experience on Android TV devices and projectors.

The vision is to combine a modern TV interface, streaming application access, and a personalized cinema-style home screen.

## Technology Stack

- Kotlin
- Jetpack Compose
- Android Studio
- Android SDK
- Material 3
- Gradle

## Current Features

- Native Android application
- Installed application discovery
- Android TV and standard launcher activity detection
- Application icons
- Launch installed applications
- Hidden system utility applications
- NaSX Cinema OS 2.0 home screen
- Home navigation UI
- Streaming service tiles
- Trending movie cards
- Cinematic hero banner layout
- My List demo interaction

## Current Development Status

The Cinema OS 2.0 homepage has been implemented and tested in the Android TV emulator.

Streaming service tiles currently use a combination of installed applications and promotional placeholders.

Movie cards and the featured movie banner are currently demo UI elements. Actual movie artwork integration and media playback are pending.

## Hardware Target

- Android TV devices
- Android projectors
- Initial physical target: Wownect 4K Mini Projector (Android 13)
